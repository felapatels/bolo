Help teach the next generation

Bolo teaches twenty-two South Asian languages. It can already show a learner the shape of each letter, but not the part you learned in school: which stroke comes first, and which way your hand moves. Only someone who writes the script can give it that.

This takes five to ten minutes, and whatever you can manage is genuinely appreciated. You can stop whenever you like and nothing is lost. Every bit helps make this a better way to teach the next generation.
