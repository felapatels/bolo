2. Self-host web fonts. src/index.css loads thirteen Noto families from Google Fonts at runtime, so offline or CDN-blocked users get the same tofu failure, and Google Fonts CDN requests leak user IPs to a third party, which is a GDPR consideration. Download the font files, serve them locally from the web app's static assets, and replace the runtime Google Fonts links with local @font-face declarations.

Three constraints: subset or use the official per-script files rather than shipping full Noto builds, since thirteen script families at full weight would bloat the bundle badly; use font-display: swap so text renders immediately in a fallback while fonts load; and add Ol Chiki and Meetei Mayek to the web set too while you're in there, since the same two gaps exist on web whenever the CDN is unreachable.

Report the total added asset weight for both platforms when done. If mobile app size grows by more than a couple of MB from the two new fonts, say so rather than silently shipping it.
