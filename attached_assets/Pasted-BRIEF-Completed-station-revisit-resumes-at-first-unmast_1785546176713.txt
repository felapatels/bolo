BRIEF: Completed-station revisit resumes at first unmastered phrase (web)

CONTEXT
Reported on dev: a station at 8/10 mastered with status Completed, when revisited from the journey map, starts the session at phrase 1 instead of the first unmastered phrase. The station-resume feature (Task #954, landed at e3972fe) defines auto-start at the first phrase with bestScore < 80, with an all-mastered fallback to phrase 1 as a review visit. A completed-but-not-perfect station (completion threshold met, some phrases unmastered) appears to take the review-visit branch instead of the first-unmastered branch.

RULING (made, implement as stated): revisiting ANY station lands on the first unmastered phrase when one exists, regardless of station completion status. Phrase 1 is the start only when every phrase in the session is mastered (bestScore >= 80). The reason a learner reopens a completed station is the phrases they have not mastered; this also aligns with the checkpoint-polish direction (target weak phrases). If Step 0 reveals the current behavior was a deliberate spec choice with a documented rationale, STOP and report before changing it.

STORY: Resume at first unmastered on every revisit
As a learner reopening a station where I have unmastered phrases,
I want the session to start at my first unmastered phrase,
So that returning to a station targets exactly the work I came back for.

Acceptance criteria:
1. The system shall start a practice session at the first phrase whose bestScore is null or below the mastery threshold, regardless of the station's completion status.
2. The system shall start at the first phrase only when every phrase in the session meets the mastery threshold, or when no per-phrase score data exists for the session (including tested-out stations without per-phrase attempts).
3. The system shall preserve the full phrase set in the session; earlier mastered phrases remain reachable via back-navigation and the manual prev/next controls.
4. The system shall apply identical behavior on every entry route into the session (journey map tap, direct link, any revisit path); entry route shall not change the start position.
5. The system shall leave teaser/taste sessions and test-out mode start behavior unchanged.
