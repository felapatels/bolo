## Items, in priority order

### 1. Floating bottom nav (bug-class, do first)

The bottom nav scrolls with content on web; on /journey (longest page in the app) it is effectively unreachable. Fix: the nav floats (fixed/sticky at viewport bottom) on all web pages, with content bottom-padding so the last element is never hidden beneath it. Check safe-area inset handling and that the chat input's keyboard behavior is unaffected. Step 0 micro-report before fixing: does the nav float correctly on any page today (map-page container swallowing, or global)? Fix at the right layer accordingly.

### 2. Home hero: the journey is the primary CTA

The "Ride the line" card currently reads as a sibling of the topic cards. Rebuild it as the home hero: full-width boarding-pass treatment in the line's accent color, visually continuous with the journey page header. It carries state, not just size: current station name and Stop N of M, progress within the current group if cheap, and an action verb (Continue your journey / Next stop: X to go). The daily-goal or streak indicator, if present on home, moves onto or adjacent to the hero. Topic grid demotes to a Browse by topic section, unchanged in function. Fire or reuse a PostHog event distinguishing journey entry via hero so the effect is measurable.

### 3. Chat time meter

Current meter (thin bar + "1:59 of 2:00 left this week") is informationally correct and emotionally inert. Rework: label it as the user's free allowance (e.g. "2 free chat minutes each week"), make depletion legible, and make the meter itself become the upgrade affordance as it runs low: at low/zero remaining, the meter area shows the All-Access prompt inline rather than only walling at zero. Report what happens today when time expires mid-conversation (hard stop vs grace) and preserve whichever it is; this changes presentation, not limits. All-Access naming per the checkpoint 1 rename.

### 4. Train icon character (interim)

Replace the current train glyph with a characterful inline SVG: side-profile engine in the line's accent color, facing direction of travel, positioned at the user's current station as the progress avatar. Small motion welcome if cheap (idle bob or smoke puff on station completion via existing animation utilities), skip if not. Interim treatment; the bespoke artwork-batch train (#801 lineage) replaces it later. Do not generate raster artwork.

### 5. Postcard furniture (interim)

Zone postcards read as plain frames. Add postcard furniture so they read as postcards without landmark art: a stamp corner (small rectangle with line accent and zone number), a circular postmark mark, a divided-back vertical rule, and the zone name styled as a handwritten-adjacent caption (existing display font weight only; no new fonts unless already bundled). The grayscale locked-zone treatment from D1b must still read correctly with the furniture. Landmark illustrations remain out of scope for the artwork effort.

### 6. Hold-to-speak affordance (practice + chat consistency)

The practice screen shows "HOLD TO SPEAK" at the bottom, visually disconnected from the actual control: the mascot. Users are not taught that the parrot is the button. Fix: (a) move the instruction to the mascot ("Hold Bolo to speak", matching chat's existing "hold my belly" copy so both surfaces teach the same gesture); (b) add an idle affordance around the mascot: a soft pulsing ring or glow signaling tappability, plus a pressed state while holding (slight scale, ring brightens); (c) a one-time first-practice coach hint pointing at the mascot if cheap, never repeated. Same interaction, zero behavior change: this teaches the existing control. Practice and chat end consistent in copy and affordance. The released-before-start mic guard behavior from the earlier fix must be untouched.

2. The system shall present the journey as the visually primary action on home, carrying current-station state and an action verb, with the topic grid secondary.
3. The system shall present the chat time meter as a labeled free allowance whose low and empty states surface the All-Access upgrade inline.
4. The system shall render the train as a characterful accent-colored avatar at the current station.
5. The system shall render zone postcards with stamp, postmark, divider, and caption furniture, legible in unlocked and grayscale locked states.
6. The system shall present the mascot as the visibly identifiable hold-to-speak control with consistent instruction copy on practice and chat, without altering recording behavior.
